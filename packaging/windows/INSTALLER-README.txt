ViewMirror / Windows 11 x64

このインストーラーは現在のユーザーだけにインストールします。
標準の保存先は %LOCALAPPDATA%\Programs\ViewMirror です。
管理者権限、MSYS2、.NET SDK、追加の.NETランタイムは不要です。
スタートメニューの「ViewMirror」から起動できます。
起動すると受信待機になります。解像度・コーデックは画面右クリックで変更します。
iPadとPCを同じ信頼できるLANへ接続し、iPadの画面ミラーリングから
「ViewMirror-Windows」を選択してください。

このアプリは未署名です。Smart App Control等により起動できない場合があります。
保護機能を無効にせず、表示されたエラーを配布者へ連絡してください。

インストーラーはファイアウォールやセキュリティ設定を変更しません。
Windowsが受信のアクセス許可を求めた場合、信頼できるPrivateネットワークだけを
選択してください。Public全体への許可やルーターのポート転送は不要です。

設定・ログは %LOCALAPPDATA%\ViewMirror に保存します。
アンインストールはWindowsの「設定 → アプリ → インストールされているアプリ」
から「ViewMirror」を選択してください。設定・ログは削除されません。
更新・アンインストール前にViewMirrorを終了してください。
同じユーザーの旧版と新版は同時起動できません。
ZIP版のREADME.txtにある削除・更新方法より、この案内を優先してください。

日本語訳はインストール先のLICENSE-ja.txtでも確認できます。
